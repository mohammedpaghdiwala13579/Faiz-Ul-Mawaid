# Chattogram Daily Tiffin (Faiz-ul-Mawaid)

A modern Next.js application for Faiz-ul-Mawaid Chattogram daily tiffin menu viewing, with authentic Dawoodi Bohra (Fatimid / Misri Tabular) Hijri calendar synchronization, live weather reporting, interactive 3D flip weekly schedule, high-resolution graphic sharing, Dua recitation, and daily feedback collection.

## Features

- **Next.js 15 App Router & TypeScript**: Modular, production-ready architecture.
- **Top of Card Single-Line Guarantee**: Arabic month, English month/date, and weekday name are engineered with responsive typography and tight chip spacing to stay strictly in a single line across all mobile devices without wrapping.
- **Compact Card Proportions**: Svelte, sleek menu cards designed for mobile ergonomics.
- **Authentic Dawoodi Bohra Tabular Hijri Calendar Engine**:
  - Exact astronomical calculations based on the Fatimid/Misri 30-year Dawr cycle.
  - Eve (Raat, after Maghrib) and Day (Dawas) phase support.
  - Authoritative Miqaat detection with full Urus, Milad, Azeem Miqaat, and Shahadat categorization.
- **3D Flip Weekly Menu Cards**:
  - Front: Day, single-line date chips, dish items with custom color accents, and Miqaat badge.
  - Back: Preparation and ingredient guidance.
  - Text-to-speech read aloud with animated sound waves.
  - Expand modal for detailed view.
- **Today's Tiffin Spotlight**:
  - Instant dish highlights, Mumineen Calendar synchronization card, and live weather widget with animated conditions for Chattogram.
- **High-Resolution Weekly Graphic Export**:
  - Clean HTML-to-canvas rendering of the complete weekly schedule for universal sharing, clipboard copying, and PNG downloading.
- **Dua & Feedback**:
  - Audio recitation player for Mawaid Niyyat Dua.
  - Daily feedback form with attached day menu and 5-star rating synced to Google Form & local storage.
- **PWA & Offline Resilience**:
  - Service worker caching and install guidance for iOS (Safari Share sheet) and Android/Desktop.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
